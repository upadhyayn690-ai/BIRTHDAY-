# Chhavi Didi Birthday Surprise

Open `index.html` in a browser, or publish free on GitHub Pages:

1. Create a free account at github.com and click New repository (name it e.g. `chhavi-birthday`, set it to Public).
2. Click "uploading an existing file", then drag in `index.html` and the whole `assets` folder (all 5 files).
3. Click Commit changes.
4. Go to Settings > Pages. Under Source choose "Deploy from a branch", Branch `main`, folder `/ (root)`, then Save.
5. Wait 1-2 minutes. Your link will be `https://YOUR-USERNAME.github.io/chhavi-birthday/`.

`index.html` must stay in the root folder and `assets/` must sit next to it.
